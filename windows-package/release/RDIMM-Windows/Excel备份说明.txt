RDIMM Windows v1.7 — Excel 备份

1. 点击页面右上角“导出 Excel”。一次将全部送样记录保存到一个 .xlsx 文件，不受搜索、筛选或排序影响。
2. 同一个 Excel 含“送样记录”“归还明细”两个工作表。数量为数字，日期可排序，批次按文本保存以保留前导零。空台账也能导出表头。
3. 文件保存在“启动RDIMM.cmd”所在目录的 back_up 文件夹；不存在时自动创建。
   文件名示例：2026-09-17_14-30.xlsx（北京时间，精确到分钟）。
   同一分钟重复导出使用 _01、_02 等序号，已有文件不会被覆盖。
4. 结束使用请点击页面“退出程序”。弹窗可选：取消、直接退出、导出后退出。
   “导出后退出”会先保存完整 Excel，保存失败保持程序运行并显示错误。
   “直接退出”不会生成 Excel，但数据库中已保存的数据仍保留。
5. 在运行窗口按 Ctrl+C 也会询问备份：输入 Y 导出并退出、N 直接退出、C 取消，然后按回车。
6. 点浏览器标签页或窗口的 ×、刷新或跳转时，会请求浏览器显示原生离开提示（须先点击或输入，与页面交互；是否显示由浏览器控制）。
   选择“取消 / 留在此页”后，页面显示备份弹窗，可选择“导出后退出”。
   选择“离开”会关闭页面，不会自动导出。浏览器不允许将原生提示文字改为“请导出数据”。
   关闭浏览器标签页不等于停止后台程序。请优先使用页面“退出程序”。
   强制结束进程、关机、断电不能保证出现提醒或完成导出。
7. back_up 中的 Excel 是可阅读的台账快照；当前程序未提供 Excel 一键恢复功能。
   data/backups 中仍保留原有 SQLite 自动备份，和 Excel 备份互不影响。

验证：本地隔离数据库功能测试、Excel 文件读取检查、排版检查和构建检查通过。
当前开发环境为 macOS，未在真实 Windows 桌面实机验证退出交互。
