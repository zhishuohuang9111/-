RDIMM 样品管理 · Windows 本地免安装版

适用：Windows 10 / Windows 11，64 位 x64 电脑。
无需安装 Node.js、Python 或其他开发软件。无需联网。

一、打开
1. 将整个 ZIP 压缩包复制到 Windows 电脑。
2. 右键压缩包，选择“全部解压缩”。建议放到“文档”文件夹下。
3. 打开解压后的 RDIMM-Windows 文件夹，双击“启动RDIMM.cmd”。
4. 浏览器会自动打开管理页面。若没有自动打开，将启动窗口内显示的网址复制到浏览器。
   默认网址：http://127.0.0.1:18736/
   默认端口被其他程序占用时，会自动使用其他端口，以窗口显示为准。
请勿直接在 ZIP 压缩包里双击运行，也不要直接双击 public 文件夹中的网页文件。

二、日常操作
新建送样：填写客户、申请人、规格、数量等，保存申请。
确认送出：在待送样记录中填写批次、实际送样日期、约定归还日期。
到期提醒：提前 7 天、当天到期和逾期的记录显示在“到期提醒”页，按北京时间计算。
登记归还：填写本次归还数量与日期，支持分次归还，自动计算剩余数量。
查看明细：点击“详情”可查看各次实际归还；也可以调整约定归还日期。

三、关闭和再次使用
使用期间保留启动后的黑色窗口。只关闭浏览器不会关闭程序。
结束使用时在黑色窗口按 Ctrl+C，或关闭这个窗口。
下次使用仍然双击“启动RDIMM.cmd”，已保存的数据会保留。
重复双击时会尝试打开已经运行的同一份程序。
提醒属于网页内提醒；程序关闭时不会弹窗，不会发送微信或邮件。

四、数据与备份
正式数据位于 data 文件夹中的 rdimm.sqlite。
数据库运行时可能同时出现 rdimm.sqlite-wal 和 rdimm.sqlite-shm，请不要删除。
每天首次重新启动时，在 data\backups 中自动备份当天启动前的数据。
手动备份或迁移到另一台电脑：先关闭程序，再复制整个 RDIMM-Windows 文件夹。
不要覆盖或删除 data 文件夹。initial-data.json 只在首次启动时导入。
此包包含打包时从 Mac 本地台账读取的数据快照，不自动同步 Mac 或线上网站的后续修改。
多台电脑各自运行时，各自的数据是独立的。

五、常见问题
没有打开：先确认已完整解压，runtime 文件夹中有 node.exe，且电脑是 Windows x64。
网址打不开：保持启动窗口打开，使用窗口内显示的网址；不要使用 Mac 的 localhost:5173 地址。
启动报错：窗口会保留错误信息，可将错误内容发给维护人员。

运行环境：Node.js v24.13.0 Windows x64（官方发行版）。许可见 runtime\LICENSE。
验证说明：已在 Mac 上验证同一份本地服务的业务流程和数据持久化；尚未在真实 Windows 电脑上实测双击启动。
