RDIMM v1.12 数据库归档与上传查看

删除所有数据：
1. 在确认弹窗填写“数据库归档名称”，默认名称包含当前北京时间，精确到分钟。
2. 自动加 .sqlite 扩展名；同名自动加序号，不覆盖已有归档。
3. 删除前将完整数据库（含报告原文件）保存到 data/finished_order。
4. 原有 back_up Excel 备份、data/backups 数据库备份继续保留；任一步失败不删除台账。
5. 归档名不支持 Windows 文件名特殊字符、路径和保留名称，最多 100 个字符。

查看历史数据库：
1. 点击“上传数据库 / 查看归档”。
2. 可以直接选择 data/finished_order 中已有归档，也可以上传 .sqlite / .db 文件。
3. 上传数据库经过格式及完整性检查后保存到 data/finished_order，同名加序号。
4. 只读查看，不会合并、恢复或覆盖当前台账。返回当前台账后可正常继续登记。
5. 历史记录每页 10 条，查询覆盖全部页；详情中可查看归还明细、下载数据库内的报告。
6. 网页上传上限 512 MB。更大的完整备份可手动复制到 data/finished_order，使用 .sqlite 后缀，再刷新归档列表。
7. 请使用本程序生成的完整数据库备份。不要直接上传仍在运行中的 rdimm.sqlite，未合并的 WAL 内容可能缺失。
8. 数据库中的报告原文件可下载。仅在 Attachment 外部副本中、未包含在数据库内的文件无法通过此页面读取。

已通过隔离数据库归档失败保护、命名、同名保护、上传验证、只读查询和历史报告读取测试；未在 Windows 实机验证。
