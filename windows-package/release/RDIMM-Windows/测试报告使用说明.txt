RDIMM v1.10 测试报告功能

1. 登记归还时必须选择客户是否提供测试报告：已提供 / 未提供。
2. 已提供时可上传一个报告附件，也可稍后从“详情 → 实际归还明细 → 补传测试报告”补传。
3. 历史归还记录显示“未登记（历史记录）”，可补传。补传成功后自动标记“已提供”。
4. 主列表新增“测试报告”列，详情显示每次归还的报告状态及“查看报告”链接。
5. 支持 PDF、PNG、JPG、DOC、DOCX、XLS、XLSX、TXT；每次归还一个文件，最大 20 MB。
   PDF、图片可在浏览器查看（也取决于浏览器设置）；其他文件下载后使用本机软件打开。
6. 报告原文件存放在 data/rdimm.sqlite 数据库中，重启后仍能查看。迁移电脑时请在程序关闭后复制整个 data 文件夹。
7. Excel 导出的“归还明细”含报告状态及文件名，不包含报告原文件。
   原有 SQLite 自动备份及删除所有数据之前的数据库备份包含报告原文件。
8. 删除整条记录会删除其归还明细及报告；删除所有数据前仍必须成功完成 Excel 与数据库备份。
9. 更新只覆盖程序文件，不要替换 data、back_up 或 initial-data.json。首次启动自动升级旧数据库结构。

已通过隔离数据库上传、补传、重复提交、归还事务回滚、重启持久化、查看/下载响应及备份测试。
已检查浏览器归还表单；尚未在真实 Windows 桌面验证。

10. 上传附件同时在程序目录 Attachment 中保存一份，按归还记录分子文件夹，文件名保留原名并加“报告_”前缀；Windows 不允许的文件名字符替换为下划线。
    同名文件不会覆盖。首次升级启动会自动从数据库补存已有报告；文件夹不可写时在运行窗口提示，下次启动重试。
    新上传时独立副本保存失败，则归还和报告均不保存，请排除文件夹权限或磁盘空间问题后重试。
    删除台账记录或删除所有数据，不会删除 Attachment 中的独立副本。
    迁移时建议同时复制 data 和 Attachment 文件夹。
