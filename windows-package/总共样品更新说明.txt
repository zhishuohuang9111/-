RDIMM Windows 本地版 v1.5

新增“总共样品”统计栏，显示当前台账中全部送样记录的申请数量合计。
总共样品 = 待送样数量 + 在外样品数量 + 累计归还数量。
这是台账记录的累计数量，不是去重后的实物库存；同一实物多次送样会按多笔记录累计。
新建、删除记录后同步更新；归还只改变在外和累计归还数量，不改变总共样品数量。
搜索和排序不会改变顶部全部台账的统计口径。

宽屏统计栏顺序：总共样品、在外样品、待送样、累计归还、需要关注。
窄屏自动换行，“需要关注”放在最后一行右侧。

更新方式
1. 关闭原程序的黑色启动窗口。
2. 解压更新包，将包内 RDIMM-Windows 中的 server.cjs 和 public 文件夹复制到原程序目录，替换同名文件。
3. 双击原来的“启动RDIMM.cmd”，必要时按 Ctrl+F5 刷新浏览器。

本更新包含此前版本功能，可直接覆盖旧版本。不包含 data、initial-data.json 或 runtime，保留已有台账。
