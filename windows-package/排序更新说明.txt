RDIMM Windows 本地版 v1.4

新增排序
列表上方的“排序”下拉框提供：
- 送出数量：从高到低 / 从低到高。
- 未归还数量：从高到低 / 从低到高。
- 约定归还日期：从近到远（日期从早到晚）/ 从远到近（日期从晚到早）。
- 默认顺序：恢复原来的列表顺序。

未约定归还日期的记录，在两种日期排序下都排在最后。
未实际送出的记录，数量显示“—”，在两种数量排序下都排在最后；已全部归还的数量 0 正常参加排序。
排序可与搜索和各列表页共同使用，只改变显示顺序，不修改台账数据或统计结果。
日期相同或数量相同时保持原有相对顺序。

更新步骤
1. 关闭原程序的黑色启动窗口。
2. 解压更新包，将包内 RDIMM-Windows 文件夹中的 server.cjs 和 public 文件夹复制到原程序目录，替换同名文件。
3. 双击原来的“启动RDIMM.cmd”；若仍显示旧界面，按 Ctrl+F5 刷新浏览器。

此包包含此前的申请人搜索、删除整条记录和删除所有数据功能，可直接更新旧版本。
更新包不能单独运行，不包含 data、initial-data.json 和 runtime，不覆盖已有台账。
