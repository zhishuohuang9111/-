RDIMM Windows 本地版 v1.1 更新说明

本次新增：删除整条送样记录。

如何更新已有 Windows 程序（保留台账数据）
1. 关闭原程序的黑色启动窗口，确保程序已经停止。
2. 如需留存旧版本，先复制整个旧 RDIMM-Windows 文件夹作为备份。
3. 解压“RDIMM-Windows-删除功能更新包-v1.1.zip”。
4. 打开更新包中的 RDIMM-Windows 文件夹。
5. 把里面的 server.cjs 文件和 public 文件夹，复制到你原来使用的 RDIMM-Windows 文件夹。
6. Windows 提示同名文件时，选择替换目标中的文件。
7. 回到原来的程序文件夹，双击“启动RDIMM.cmd”；如浏览器还显示旧页面，按 Ctrl+F5 刷新。

这个更新包仅包含 server.cjs 和 public，不包含 data、initial-data.json 或运行环境。
不需要重新清空数据，不要删除或替换原程序的 data 文件夹。
更新包不能单独运行，必须覆盖到原程序目录；不要把整个新文件夹嵌套到旧文件夹中。

如何删除
1. 在任意送样列表中，点击对应行的红色“删除”。
2. 确认客户、编号、数量以及关联归还明细笔数。
3. 点击“确认删除整条记录”。点击“取消”则保留原记录。
4. 该笔送样及其所有归还明细一起删除，记录数、在外数量、待送样数量、累计归还和到期提醒立即重新计算。

删除成功后，重新打开程序也不会恢复该记录；无法在页面内撤销。
删除其中一笔送样不会删除同一客户的其他送样记录。
本次更新适用于 Windows 本地版，线上网站不会随此更新包自动改变。

验证：已验证删除、关联数据、失败回滚、数据重启保留及原有业务流程。
当前未在真实 Windows 电脑上实测双击启动。
