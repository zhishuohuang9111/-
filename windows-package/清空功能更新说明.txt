RDIMM Windows 本地版 v1.2 更新说明

新增“清空所有数据”，同时保留上一版的“删除整条记录”。

更新步骤
1. 关闭原程序的黑色启动窗口。
2. 解压此更新包，将里面 RDIMM-Windows 文件夹中的 server.cjs 和 public 文件夹复制到原程序目录，选择替换同名文件。
3. 保留原来的 data、runtime 和 initial-data.json，不用删除或修改它们。
4. 双击原来的“启动RDIMM.cmd”。如果仍显示旧页面，在浏览器按 Ctrl+F5 刷新。
此包为更新包，不能单独运行；可以直接覆盖最初版本或 v1.1。

清空并重新建立
1. 点击页面右上方“清空所有数据”。
2. 确认提示中的送样记录数、归还明细数。
3. 点击“确认清空所有数据”；点击“取消”不会改变数据。
4. 程序先备份，再清空当前台账。记录数、在外数量、待送样、累计归还和到期提醒归零。
5. 点击“新建送样”开始建立新台账。
没有数据时，清空按钮不可用。

保留的内容
- data 文件夹和数据库文件继续使用，不删除文件夹，不重建数据库结构。
- 清空前生成的独立备份保存在 data\backups\before-reset-日期时间-编号.sqlite。
- 以前的备份也会保留。清空当前台账不代表删除历史备份。
- 数据库的初始化标记保留，因此重启不会再导入 initial-data.json 中的旧数据。
- 无需修改 initial-data.json。

失败处理
备份失败不会清空。删除中途失败会回滚，原送样和归还数据保留。
清空操作不能在页面内直接撤销。如确需恢复，可以从清空前的备份恢复。

验证范围
已在隔离测试数据中验证清空、备份内容、失败回滚、数据文件保留、重启为空台账和清空后重新录入。
尚未在真实 Windows 电脑上实测双击启动。
