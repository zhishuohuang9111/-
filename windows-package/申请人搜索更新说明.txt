RDIMM Windows 本地版 v1.3

本次更新
1. 搜索框支持按申请人姓名查找，与客户、批次、规格、记录编号共用同一个搜索框。
   输入完整姓名或姓名的一部分即可；会在当前选中的列表内筛选。
2. “清空所有数据”统一改名为“删除所有数据”，包括按钮、确认弹窗和操作提示。
   功能保持不变：删除前自动备份，删除全部送样及归还记录，统计和提醒归零，保留 data 文件夹和备份。

更新步骤
1. 关闭原程序的黑色启动窗口。
2. 解压更新包。
3. 将包内 RDIMM-Windows 文件夹中的 server.cjs 和 public 文件夹，复制到原程序目录并替换同名文件。
4. 双击原来的“启动RDIMM.cmd”，必要时按 Ctrl+F5 刷新浏览器。

本包可直接更新最初版本、v1.1 或 v1.2，保留之前新增的删除整条记录和删除所有数据功能。
本包不含 data、initial-data.json、runtime；不修改已有台账。不要删除原来的 data 文件夹。
更新包不能单独运行，须覆盖到已安装的 Windows 本地版目录。
